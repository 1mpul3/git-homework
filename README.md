# git-homework

Учебный репозиторий для домашнего задания по Git и GitHub.

## Цель работы

Отработать базовый рабочий процесс:

1. создать удалённый репозиторий;
2. склонировать его на локальную машину;
3. добавить файлы `README.md` и `index.html`;
4. сделать несколько коммитов и отправить их на GitHub.
